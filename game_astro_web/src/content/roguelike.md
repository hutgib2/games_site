## Description
Roguelike is an endless game where you shoot regular squares, speedy squares and boss squares. Try to survive for as long as possible, while collecting fun powerups to help you stay alive. You have 3 lives before you die, the aim is to collect as many points as you can by eliminating sqaures before the innevitable happens...


## How to Play
- Press esc to return to main menu
- Arrow keys/WASD to move 
- Space to shoot 
	- while stationary bullets fire in random directions
	- while moving bullets fire in the opposite direction
